# GAWAZ INN — Technical Risks & Mitigations

| # | Risk Category | Description & Impact | Likelihood | Severity | Mitigation Strategy |
|---|---|---|---|---|---|
| 1 | **No Backend / Database** | Current app stores all orders, National IDs, support cases, and state solely in `localStorage`. Zero multi-user persistence, zero server authorization, data loss on browser clear. | Certain (Existing) | **Critical** | Build real Node/TypeScript API server (`server/`) backed by relational SQLite (`node:sqlite`, built into Node 24) with normalized tables, foreign keys, migrations, plus PostgreSQL/Supabase migration parity (`db/migrations/`) and Vercel serverless adapter (`api/`). |
| 2 | **Client-Side Auth & PII Exposure** | `AuthModal` grants login without credentials; `CustomerPortalView` renders all records regardless of owner; `nationalId` stored plaintext in `localStorage`. | Certain (Existing) | **Critical** | Implement real password/OTP-flow simulation with `scrypt` hashed passwords, HMAC-signed session tokens (`HttpOnly` cookies / Bearer tokens), server-side RBAC middleware (`customer`, `vendor`, `expert`, `moderator`, `editor`, `admin`, `super_admin`), ownership checks on every query, and National ID masking/encryption-at-rest. |
| 3 | **Vercel Static Deployment vs. Local DB Persistence** | Vercel serves static `dist/` or ephemeral serverless functions without a persistent filesystem. Writing to local SQLite in serverless `/tmp` will not survive cold starts. | High | **High** | Support dual-ready repository layer: `node:sqlite` for local full-stack execution/testing & PostgreSQL (`DATABASE_URL` / Supabase) for production Vercel deployment; clearly isolate and document pending production DB/provider env vars in `INTEGRATION_STATUS.md` and keep safe demo-mode fallback when no API host is attached. |
| 4 | **Bundle Size Bloat** | Baseline single JS bundle is already `524.79 kB` (> 500 kB Vite limit). Adding 20+ modules naively could push initial JS > 2 MB, hurting mobile performance. | High | **High** | Enforce route-based `React.lazy()` + `Suspense` code splitting, manual Vite/Rolldown chunks (`vendor`, `calculators`, `encyclopedia`, `admin`), and lazy-loaded heavy modals/charts. |
| 5 | **Scope Creep & Broken Cross-Module Links** | 21 product modules (A–U) plus Admin OS could easily degrade into disconnected pages with duplicated formulas or inconsistent state. | High | **High** | Build Stage 1 core foundations first: centralized `src/lib/calculators/` calculation engine, unified relational schema, shared `ApiClient`, and cross-module event/integration links (calculator → shopping list → RFQ → budget → journey). |
| 6 | **Design System Drift** | Reusing orphaned Navy/Gold (`#17243A`) components or introducing generic blue SaaS admin/dashboard tables would violate the strict "Do Not Redesign" constraint. | Medium | **High** | Remove/quarantine Navy/Gold legacy code; enforce `DESIGN_SYSTEM_REFERENCE.md` tokens (`#D91B3E`, `#FFFFFF`, `#FAF7F2`, `#1C1819`, Cairo font) across all 12 stages and inspect in headless Chrome after every stage. |
| 7 | **SEO Crawlability of Client SPA** | Pure client-side React routing doesn't give search engines pre-rendered HTML per route or dynamic meta tags/JSON-LD/sitemap. | High | **Medium** | Implement clean URL routing (`react-router-dom` or History router), dynamic document head manager (title, meta description, canonical, OG, JSON-LD), static `public/robots.txt` + generated `sitemap.xml`, and pre-rendering/SSR-ready route manifest documented for Vercel rewrites. |
| 8 | **Broken External Media & Fabricated Commercial Data** | Live `bride-p1` Unsplash image is 404; external URLs can rot; inventing fake verified vendors or real-time prices violates data integrity rules. | Confirmed (Existing) | **Medium** | Replace broken URLs, add `onError` resilient image fallbacks, label all seed/estimate data explicitly with `source`, `isEstimate`, `isDemoData`, and `lastUpdatedAt`, and verify all asset URLs in automated tests. |
| 9 | **RTL / Mobile Layout Regressions** | Confirmed live bug where `start-1/2 -translate-x-1/2` clips `GroomView` sticky bar `-319px` off-screen on mobile RTL. | Confirmed (Existing) | **Medium** | Standardize physical centering (`left-1/2 -translate-x-1/2` or `inset-x-0 mx-auto`), enforce Tailwind logical spacing (`ps/pe/ms/me/start/end`), and assert `scrollWidth <= clientWidth` across `1440px` and `375px` in Playwright after every stage. |
| 10 | **Missing External Credentials** | Email (SMTP/Resend), WhatsApp Cloud API, Payment Gateways (Paymob/Fawry), Maps, Object Storage, and LLM API keys are not configured in workspace. | Certain | **Medium** | Implement clean provider interfaces (`server/integrations/`) with safe internal workflow persistence and clear `disabled/unconfigured` status badges; never fabricate credentials or fake live payment/SMS confirmations. |
